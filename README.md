## 🌟 100% 완전 클론 특징

- **🌱 파이프 뻐끔플라워(Piranha Plant) 시스템**:
  - 2, 3, 6번 파이프에서 2프레임 뻐끔거림 입 애니메이션으로 상하 출현
  - **근접 감지 센서**: 마리오가 파이프 반경 24px 이내에 서 있으면 절대 나오지 않는 원작 고증 100% 반영
  - 파이어볼 또는 무적 스타맨 접촉 시 격파 가능 (+200점)
- **🧱 10연타 멀티코인 벽돌 (x=94, row 5)**:
  - 첫 타격 시 타이머 시작, 제한 시간 내 연속 타격 시 최대 10개 이상의 코인 획득 후 빈 블록(`EMPTY_BLOCK`)으로 변환
- **🎆 성문 깃발 상승 & 불꽃놀이(Fireworks) 축하 연출**:
  - 깃대 착지 후 성 상단 포탑의 미니 삼각 깃발이 꼭대기로 스르륵 상승
  - **원작 불꽃놀이 규칙**: 깃대 접촉 시 남은 시간의 끝자리가 **1, 3, 6**이면 각각 **1회, 3회, 6회의 축하 폭죽**이 성 상공에서 저음 포격 폭발음과 함께 터지며 개당 +500점 보너스 획득
- **⏸️ 원작 고증 포즈(Pause) 시스템**:
  - <kbd>Enter</kbd> 누르면 원작 특유의 4음 연속 펄스 아르페지오(`C6 -> E6 -> G6 -> C7`) 차임음과 함께 게임 정지 및 `PAUSE` 표시
- **👥 2-Player 루이지(Luigi) 모드**:
  - 타이틀 화면에서 <kbd>Shift</kbd>(Select) 누르면 버섯 커서가 1P / 2P 이동
  - 2P 선택 시 원작 1985년 클래식 녹색 모자/셔츠 + 흰색 멜빵 배색의 루이지로 플레이 가능
- **🔥 파이어 마리오 던지기 전용 프레임 & 스타맨 4단 무지개 팔레트**:
  - 파이어볼 발사 시 팔을 전방으로 뻗는 16×32 전용 모션 프레임 연출
  - 스타맨 획득 시 4프레임 주기로 색상이 반짝이며 회전
- **🕹️ 60FPS 서브픽셀 NES 물리 엔진**:
  - 가변 점프 높이: 점프 버튼 체공 시간에 비례한 점프 높이 제어
  - 가속도 및 관성 보행/질주 (대시 시 2.56 px/f)
  - 급제동(스키드) 동작, 흙먼지 파티클 및 전용 사운드
  - 1칸 낭떠러지 전력질주 통과
  - 블록 밑치기 충격파 (작은 마리오는 튕김, 슈퍼 마리오는 벽돌 파괴, 상단 굼바 뒤집힘 즉사)
- **👾 4단 상태 머신 & 적 메커니즘**:
  - 꼬마 마리오, 슈퍼 마리오, 파이어 마리오(파이어볼 투척), 무적 스타 마리오
  - 굼바 찌그러짐 판정, 엉금엉금 등껍질 차기 및 벽면 바운스 연쇄 킬 콤보
- **🗺️ 완벽한 World 1-1 레벨 & 4번 파이프 지하 보너스 방**:
  - 원작의 모든 타일, 물음표 블록, 버섯/스타/코인 위치 100% 일치
  - 4번 파이프 숙이기(<kbd>▼</kbd> / <kbd>S</kbd>)로 지하 19개 코인 방 입장 및 출구 워프
  - 깃대 착지 높이에 따른 보너스 점수(100~5000점) 및 성문 입장 시퀀스
- **🔊 Web Audio API 기반 8-bit APU 사운드 합성 (외부 오디오 파일 0%)**:
  - 2 Pulse + 1 Triangle + 1 Noise 채널을 활용한 지상, 지하, 스타, 팡파르, 게임오버 BGM
  - 점프, 코인, 파워업, 파이프, 킥, 포즈, 폭죽 등 모든 효과음 실시간 합성
- **📱 반응형 컨트롤**:
  - 데스크톱 키보드 조작 및 모바일/태블릿용 가상 D-Pad / B, A 버튼 지원
  - 📺 레트로 CRT 브라운관 스캔라인 필터 On/Off 토글

## 🎮 조작 방법

### 키보드
| 동작 | 키 |
|---|---|
| **이동** | <kbd>◀</kbd> <kbd>▶</kbd> 또는 <kbd>A</kbd> <kbd>D</kbd> |
| **앉기 / 파이프 진입** | <kbd>▼</kbd> 또는 <kbd>S</kbd> |
| **점프 (A 버튼)** | <kbd>Z</kbd> 또는 <kbd>K</kbd> 또는 <kbd>Space</kbd> |
| **대시 / 파이어볼 (B 버튼)** | <kbd>X</kbd> 또는 <kbd>J</kbd> |
| **모드 선택 (Select 1P / 2P)** | <kbd>Shift</kbd> 또는 <kbd>Tab</kbd> |
| **시작 / 일시정지 (Start / Pause)** | <kbd>Enter</kbd> |

### 터치 (모바일/태블릿)
- 화면 좌측 하단 가상 D-Pad 및 우측 하단 B / A 액션 버튼
